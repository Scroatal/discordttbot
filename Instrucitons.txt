Discord TikTok/X Link Converter and Music Bot

Setup:

1. Create a .env file in this folder:

DISCORD_BOT_TOKEN=your_new_discord_bot_token

2. Enable Message Content Intent in the Discord Developer Portal for the bot.

3. Install ffmpeg and make sure it is available in PATH.

4. Start locally on Windows with start_bot.bat.

Behavior:

- TikTok links are replied to with kktiktok.com embed-fix links.
- Twitter/X links are replied to with fxtwitter.com or fixupx.com embed-fix links.
- YouTube, YouTube Music, and youtu.be links are played in the sender's current voice channel using yt-dlp and ffmpeg.
- The bot ignores bot-authored messages and does not run any AI/Ollama/Gemini responder.
